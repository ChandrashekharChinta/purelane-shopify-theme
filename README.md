# Purelane Shopify Theme

A responsive and conversion-focused Shopify theme developed for Purelane as part of an AI Engineer technical assignment.

## Overview

This project recreates the provided Purelane design reference as a Shopify Online Store theme.

The implementation focuses on:

- Responsive design
- Clean and reusable Shopify Liquid sections
- Mobile-first layout
- Conversion-focused UI
- Interactive components
- Product-focused presentation
- FAQ and ingredient sections
- Smooth animations and visual interactions
- Maintainable Shopify theme structure

## Features

- Responsive homepage
- Announcement bar
- Hero section
- Product-focused sections
- Ingredient section
- Benefits / feature sections
- FAQ section
- Responsive navigation
- Mobile-friendly layouts
- Custom animations and interactions
- Shopify Liquid-based sections
- Semantic HTML structure
- Responsive CSS
- JavaScript interactions

## Tech Stack

- Shopify Liquid
- HTML5
- CSS3
- JavaScript
- Shopify Online Store Theme Architecture
